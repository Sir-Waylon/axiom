# Gap analysis against popular learning apps

| Area | Common approach | Here |
|---|---|---|
| Bite-size lessons | Duolingo, Brilliant | Short cards then practice |
| Interactive questions | Brilliant | Graphs, sliders, angles, compass, ordering, proofs |
| Adaptive practice | Khan, Duolingo | On-device model that tracks topic and question format strength |
| Game loop | Blooket | Coins, packs, characters (cosmetic only) |
| Worked solutions | Khan | Every question has steps |
| Where others are better | Large video libraries (Khan), live multiplayer (Blooket) | Not duplicated; link to references |
