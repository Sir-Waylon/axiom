# Axiom

Algebra 1 to Geometry Honors readiness trainer: lessons, interactive labs, proofs, unit tests, test-out, endless practice.

## Deploy (Cloudflare, free)
1. Create a GitHub repo and upload everything in this folder (GitHub web: Add file > Upload files).
2. Cloudflare dashboard > Workers & Pages > Create > Pages > Connect to Git > pick the repo.
3. Build command: none. Output directory: `/` (root). Save and deploy.
4. Each push redeploys. `_headers` is applied automatically.

See LEARNING_DESIGN.md and SECURITY.md.
